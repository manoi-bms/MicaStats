# Issue tracker: Local Markdown

Specifications live at `.scratch/<feature>/spec.md`. Each implementation ticket has its own file under `.scratch/<feature>/issues/<NN>-<slug>.md`, numbered in dependency order.

Each ticket records Status, Blocked by, acceptance criteria and verification evidence. Work only when its blockers are complete. Read the ticket and its comments before implementing it. Publish locally, not to remote issues.

Use the readiness labels in `triage-labels.md`, `in-progress` during work, and `complete` only after verified acceptance. Record discussion under Comments.
