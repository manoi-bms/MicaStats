# Triage labels

| Label | Meaning |
| --- | --- |
| `needs-triage` | Requires evaluation |
| `needs-info` | Waiting on missing information |
| `ready-for-agent` | Specified and ready to implement |
| `ready-for-human` | Requires human action |
| `wontfix` | Will not be implemented |

These are local status values; configuring them creates no remote labels.
